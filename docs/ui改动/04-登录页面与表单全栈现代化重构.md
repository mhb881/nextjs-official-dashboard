# 登录页面 (Login Page) 与认证表单现代化重构设计规范

> 本文档详细记录了以 `src/app/page.tsx`、`src/ui/dashboard/sidenav.tsx` 为设计标杆，对登录路由页面（`src/app/login/page.tsx`）与认证表单（`src/ui/login-form.tsx`）进行的全栈现代化 UI 与交互重构过程、设计规范与工程实现。

---

## 一、 背景与原版短板诊断

在全站首页与发票表单完成规范重构后，登录页作为全站用户鉴权的核心入口，原版存在显著的视觉脱节与交互欠缺：

### 1. 缺乏品牌形象与视觉锚点（缺少 Acme Banner）
* **原版现象**：登录页直接使用一个无外边框的单调灰底容器（`bg-gray-50`），直接摆放了粗糙的登录输入框，既无 Acme Logo 标识，也没有返回首页的导流机制，显得孤立冷清。
* **重构方案**：
  - 引入与首页同源的 **Acme 品牌 Header Banner**，采用 `bg-gradient-to-r from-blue-600 via-blue-500 to-indigo-600` 渐变与背景微光晕。
  - 顶部增加轻量级 **Back to home** 返回导航，页面右下角增加微型安全背书提示。

### 2. 输入体验生硬且缺乏视觉反馈
* **原版现象**：输入框采用 `outline-2`，前缀图标（`AtSignIcon`、`KeyIcon`）置灰静态无变化。
* **重构方案**：
  - 采用全站一致的 `rounded-xl border border-gray-200 bg-gray-50/50 py-2.5 pr-4 pl-10 text-sm shadow-xs`。
  - 引入 `peer-focus:text-blue-600` 与 `focus:ring-2 focus:ring-blue-500/20`，输入焦点激活时前缀图标与边框同时点亮品牌蓝。

### 3. 缺少密码明密文切换（Show/Hide Password）
* **原版现象**：密码输入框强制 `type="password"`，无法直观核对输入内容，在移动设备上极易误触。
* **重构方案**：
  - 封装受控状态 `showPassword`，在密码框右侧集成轻量眼睛切换图标（`EyeIcon` / `EyeOffIcon`），支持无障碍 `aria-label`。

### 4. 提交过程缺乏 Loading 与防重复提交保护
* **原版现象**：按钮使用静态 `Button`，在 React 19 的 `useActionState` 请求中（`isPending` 为 `true`），按钮依然保持可点击外观，用户容易由于无感知而连续点击多次。
* **重构方案**：
  - 增加 `disabled={isPending}` 与 `disabled:cursor-not-allowed disabled:opacity-60 disabled:pointer-events-none` 样式抑制。
  - `isPending` 期间展示旋转加载器（`Loader2Icon animate-spin`）与动态文案 `"Signing in..."`。

### 5. 开发者体验（DX）与演示体验优化：一键填入 Demo 账号
* **痛点**：全栈开发者或面试官在本地运行与演示时，常需去查看种子脚本或环境变量寻找测试密码。
* **重构方案**：
  - 表单底部贴心设计了 **Demo Credentials 快速填入胶囊**，展示测试账号（`user@email.com` / `12345`），点击 "Quick fill" 即可一键填入表单，大幅提升验收与演示效率。

## 二、 核心变更对照清单

| 模块 / 区域 | 原版实现 | 现代化优化实现 | 设计收益与用户体感 |
| :--- | :--- | :--- | :--- |
| **页面布局与氛围** | 居中裸放灰底表单，无品牌感 | 居中全屏渐变光晕背景 + 品牌顶部卡片 + 返回首页导航 | 建立强烈且可信赖的企业级 SaaS 视觉形象 |
| **品牌 Header** | 缺失 | `AcmeLogo` + 动态渐变背景 + 2.0 徽章胶囊 | 与首页 Banner 风格完全统一，形成品牌闭环 |
| **表单外层卡片** | 简陋灰底 `rounded-lg bg-gray-50` | `rounded-2xl border border-gray-200/90 bg-white p-6 sm:p-8 shadow-xl` | 提升信息密度，质感通透有层次 |
| **输入框焦点交互** | 浏览器默认 outline，静态置灰图标 | `rounded-xl` + `peer-focus:text-blue-600 focus:ring-2 focus:ring-blue-500/20` | 输入焦点跟手度极高，消除视觉顿挫 |
| **密码可见性切换** | 无 | `EyeIcon` / `EyeOffIcon` 交互切换按钮 | 降低误输概率，提升表单可用性与可访问性 |
| **提交状态反馈** | 纯静态文字 | 防重 `disabled` + 动态旋转 Spinner（`Signing in...`） | 消除卡死疑虑，拦截高频重复提交 |
| **错误提示展示** | 底部冷冰冰单行红字 | 通栏警示条：`bg-red-50/90 border-red-200` + `AlertCircleIcon` | 醒目直观，消除布局跳动（CLS） |
| **演示辅助功能** | 无 | 底部 `Demo Credentials` 一键填入卡片 | 极大提升日常调试与演示验收效率 |

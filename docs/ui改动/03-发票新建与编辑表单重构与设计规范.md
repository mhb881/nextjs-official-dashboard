# 发票新建与编辑表单组件 UI 与交互重构设计规范

> 本文档详细记录了针对发票创建表单（`src/ui/invoices/create-form.tsx`）与编辑表单（`src/ui/invoices/edit-form.tsx`）的现代 UI 与交互重构规范，使其视觉层次、输入质感、状态选择交互、校验反馈以及操作响应与项目统一设计体系（`page.tsx`、`sidenav.tsx`、`02-控制台全站组件规范重构与设计体系.md`）保持高度一致。

---

## 一、 原版表单问题诊断

在全站控制台完成组件规范重构后，表单页面作为最关键的数据录入与编辑入口，仍存在以下设计与交互短板：

### 1. 容器与包裹层级生硬
- **原版问题**：外层容器使用粗糙的 `rounded-md bg-gray-50 p-4 md:p-6`，无边框层次，与整体控制台卡片的 `rounded-xl border border-gray-200/80 shadow-xs` 质感割裂。
- **改进方案**：升级为 `rounded-xl border border-gray-200/80 bg-gray-50/80 p-5 shadow-xs md:p-6 space-y-5`，强化内外层收敛与呼吸感。

### 2. 输入框体与图标聚焦脱节
- **原版问题**：输入框采用 `rounded-md border border-gray-200 py-2 pl-10 text-sm outline-2`，聚焦时为系统默认生硬 outline，且左侧前缀图标（`UserCircleIcon`、`CurrencyIcon`）为死色静态置灰，缺乏交互联动。
- **改进方案**：
  - 统一为 `rounded-lg border border-gray-200 bg-white py-2.5 pr-8 pl-10 text-sm shadow-xs outline-none transition-all duration-200 placeholder:text-gray-400 focus:border-blue-500 focus:ring-2 focus:ring-blue-500/20`。
  - 前缀图标采用 `peer-focus:text-blue-600 transition-colors duration-200`，聚焦时图标与边框同时被品牌蓝点亮。
  - 金额输入框统一使用等宽字体 `font-mono`，数字排印更专业，并将图标统一为 `CircleDollarSignIcon`。

### 3. 单选状态选择交互生硬简陋
- **原版问题**：单选状态（Pending / Paid）在一个白底方框内使用小圆点加胶囊徽章，无论单选框是否选中，徽章都是常驻高饱和色（Paid 一直是亮绿），交互语义失真，点击靶心过小，无按压动效。
- **改进方案**：
  - 升级为现代化**分段交互卡片（Segmented Radio Cards）**。
  - 栅格化布局：`grid grid-cols-1 gap-3 sm:grid-cols-2`。
  - 采用现代 Tailwind CSS `has-checked:*` 选择器：
    - **Pending 卡片**：未选时为白底中性灰，悬浮时轻微泛暖黄 `hover:border-amber-300 hover:bg-amber-50/40`；选中时激活 `has-checked:border-amber-300 has-checked:bg-amber-50/60 has-checked:ring-1 has-checked:ring-amber-400/30`，右侧时钟图标容器联动高亮。
    - **Paid 卡片**：未选时为白底中性灰，悬浮时轻微泛淡绿 `hover:border-emerald-300 hover:bg-emerald-50/40`；选中时激活 `has-checked:border-emerald-300 has-checked:bg-emerald-50/60 has-checked:ring-1 has-checked:ring-emerald-400/30`，右侧对勾图标容器联动高亮。
  - 整体卡片支持 `active:scale-[0.99]` 微触感缩放。

### 4. 字段校验与全局错误展示粗糙
- **原版问题**：Zod 字段校验错误仅为几行单纯的红字 `<p className="mt-2 text-sm text-red-500">`，且在输入框与错误信息间缺乏结构隔离；全局服务端异常信息没有独立警示卡片。
- **改进方案**：
  - **字段错误**：封装为包含 `AlertCircleIcon` 的微型警示胶囊 `flex items-center gap-1.5 rounded-md border border-red-200/60 bg-red-50/80 px-2.5 py-1 text-xs font-medium text-red-600`，结构醒目且不突兀。
  - **全局错误**：表单顶部设置独立全局警示条，当 `state.message` 存在时渲染 `rounded-lg border border-red-200 bg-red-50/80 p-3.5 text-xs text-red-700 shadow-2xs`。
  - **无障碍（a11y）规范**：严格保留 `aria-describedby`、`aria-live="polite"` 与 `aria-atomic="true"`。

### 5. 操作按钮质感与行为对齐
- **原版问题**：取消按钮与提交按钮高度、边框和微动效不统一。
- **改进方案**：
  - **取消按钮**：`rounded-lg border border-gray-200 bg-white px-4 text-sm font-medium text-gray-700 shadow-2xs transition-all duration-200 hover:bg-gray-50 active:scale-95`。
  - **提交按钮**：`group flex h-10 items-center gap-2 rounded-lg bg-blue-500 px-5 text-sm font-medium text-white shadow-xs transition-all duration-200 hover:bg-blue-600 hover:shadow active:scale-95`，内置箭头图标在 hover 时产生轻微位移 `group-hover:translate-x-0.5`，提供明确的方向性与前进心理预期。

## 二、 核心变更对照清单

| 区域 / 模块 | 原版实现 | 优化后实现 | 改进收益 |
| :--- | :--- | :--- | :--- |
| **表单外层卡片** | `rounded-md bg-gray-50 p-4 md:p-6` | `rounded-xl border border-gray-200/80 bg-gray-50/80 p-5 shadow-xs md:p-6 space-y-5` | 统一项目 `rounded-xl` 外框与 `shadow-xs` 质感，间距更通透 |
| **客户下拉框** | `rounded-md py-2` + 静态灰色前缀图标 | `rounded-lg py-2.5 shadow-xs focus:ring-2 focus:ring-blue-500/20` + `peer-focus:text-blue-600` | 输入框高度提升，图标与焦点实时联动 |
| **金额输入框** | `rounded-md py-2` + 常规文字排印 | `rounded-lg py-2.5 font-mono shadow-xs` + `CircleDollarSignIcon` | 金额数值等宽排印更清晰，消除图标不一致 |
| **状态单选组** | 白底方框内小圆点与静态胶囊 | 响应式分段卡片（Pending 琥珀暖色 / Paid 翠绿），支持 `has-checked:*` 状态联动 | 点击区域扩大 300%，色彩语义与选择状态严格一致 |
| **字段错误提示** | 裸文本 `<p text-red-500>` | 警示徽章：微边框浅红底 + `AlertCircleIcon` 矢量图 | 视觉层次清晰，避免页面内容闪烁突兀 |
| **全局错误通知** | 底部冷冰冰单行文字 | 顶部带边框阴影的通栏警示条，包含错误图标与提示 | 第一时间向用户传达服务端处理异常 |
| **底部操作栏** | 简单灰底 Cancel + 静态 Button | 取消键（白底微边框 + `active:scale-95`）+ 提交键（品牌蓝渐变微光 + 箭头位移动效） | 建立清晰的视觉行动号召（Primary vs Secondary CTA） |

## 三、 代码结构一致性

`create-form.tsx` 与 `edit-form.tsx` 保持了完全一致的视觉与交互实现规范，两者的核心差异仅保留在功能职责层面：
1. `createInvoice` vs `updateInvoiceWithId` 的 Server Action 绑定。
2. 编辑表单默认带有 `defaultValue={invoice.customer_id}`、`defaultValue={invoice.amount}` 及 `defaultChecked={invoice.status === '...'}`。
3. 提交按钮文案分别为 `Create Invoice` 与 `Edit Invoice`。

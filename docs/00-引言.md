# 引言（Introduction）/ App Router

欢迎来到 Next.js 基础课程！在这门免费的交互式实战课程中，你将通过完整构建一个全栈 Web 应用，系统掌握 Next.js 的核心特性。

## 本课程将构建的项目

![image-20260927055249593](./00-引言.assets/image-20260927055249593.png)

在课程中，我们将构建一个财务仪表盘（Financial Dashboard），包含以下功能：

- 公开访问的首页。
- 登录认证页面。
- 受身份验证保护的仪表盘页面。
- 发票（Invoices）的增、删、改、查能力。
- 配套的数据库系统（将在后续章节中完成配置）。

学完本课程后，你将具备开发全栈 Next.js 生产级应用所需的核心技能。

## 课程概览

以下是你在本课程中将要学习的技术特性：

- **样式方案（Styling）**：在 Next.js 中组织与编写应用样式的不同途径。
- **性能优化（Optimizations）**：如何针对图像（Images）、站内链接（Links）以及字体（Fonts）进行自动化与针对性优化。
- **路由系统（Routing）**：如何利用基于文件系统的路由（File-system Routing）构建嵌套布局（Nested Layouts）与多级页面。
- **数据获取（Data Fetching）**：如何在 Vercel 上搭建 Postgres 数据库，以及服务端数据拉取与流式传输（Streaming）的最佳实践。
- **搜索与分页（Search and Pagination）**：如何以 URL 查询参数（URL Search Params）为单一事实源实现搜索与分页。
- **数据变更（Mutating Data）**：如何使用 React Server Actions 变更数据，并精准触发 Next.js 缓存重新生效（Cache Revalidation）。
- **错误处理（Error Handling）**：如何优雅捕获通用异常与处理 404 Not Found 状态。
- **表单校验与无障碍访问（Form Validation and Accessibility）**：服务端表单校验方案，以及提升无障碍访问能力（a11y）的关键技巧。
- **身份验证（Authentication）**：如何结合 NextAuth.js 与 Proxy 为全栈应用接入认证鉴权链路。
- **元数据管理（Metadata）**：如何配置 SEO 元数据并完善社交媒体分享卡片。

## 前置知识与系统要求

- **前置知识**：本课程假定你已掌握 JavaScript 与 React 基础。若尚未熟悉组件、props、state、hooks，或未了解过服务端组件（Server Components）与 Suspense 等新特性，建议先学习《React Foundations》基础课程。
- **系统要求**：已安装 Node.js 20.9 或更高版本；操作系统支持 macOS、Windows（包括 WSL）或 Linux；准备好 GitHub 账号与 Vercel 账号。

准备就绪后，即可进入第 1 章：Getting Started（快速上手：初始化项目并启动本地开发服务）。
